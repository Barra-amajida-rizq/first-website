# Personal Portfolio - Barra Amajida Rizq

Portfolio website responsif yang menampilkan profil, keahlian, proyek, dan sertifikat saya sebagai mahasiswa Sistem Informasi di Universitas Gunadarma.

## 🚀 Fitur Utama

* **Smooth Scrolling:** Navigasi antar bagian halaman yang mulus menggunakan JavaScript kustom.
* **Animasi Interaktif:** Efek ripple pada tombol, animasi fade-in saat scroll, dan efek floating pada foto profil.
* **Responsive Design:** Tampilan yang optimal di berbagai perangkat (Desktop, Tablet, Mobile).
* **Sertifikat & Portfolio:** Galeri karya dan pencapaian akademik yang terintegrasi dengan tautan eksternal.

## 🛠️ Teknologi yang Digunakan

* **HTML5:** Struktur konten.
* **CSS3:** Styling, Flexbox, Grid, dan Keyframe Animations.
* **JavaScript (Vanilla):** Logika animasi, scroll spy, dan manipulasi DOM.
* **Google Fonts:** Menggunakan font 'Montserrat' dan 'Newsreader'.

## 📂 Cara Penggunaan Local

1. Clone repositori ini atau unduh file ZIP.
2. Pastikan struktur folder sesuai (letakkan gambar di folder `assets/img/`).
3. Buka file `index.html` di browser pilihan Anda.
